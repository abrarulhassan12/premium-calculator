# 🧮 Calculus — Premium Calculator

A modern, responsive, and feature-rich calculator built with **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

🔗 https://abrarulhassan12.github.io/premium-calculator/

## ✨ Features

- 🌙 Dark / Light theme toggle
- 🧮 Basic calculator operations
- 🔬 Scientific calculator mode
- 📜 Calculation history
- 💾 Memory functions (MC, MR, M+, M-)
- 🔊 Button sound effects
- 📋 Copy result button
- ⌨️ Keyboard support
- 🎨 Premium glassmorphism UI
- 🌌 Animated canvas background
- 📱 Fully responsive design
- ⚡ Smooth animations and transitions

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Canvas API

## ▶️ How to Run Locally

Clone the repository:

```bash
git clone https://github.com/abrarulhassan12/premium-calculator.git
```

Open the project folder:

```bash
cd premium-calculator
```

Run the project by opening:

```
index.html
```

No installation or dependencies required.
